## 3.8 재실행

- 사용자 요청으로 같은 조건(텍스트 1건, 병렬 2분기, 재시도 0회)으로 gemini-3.8-flash를 다시 실행.
- requestId: 4b394f2a-1b2e-4421-9cc9-ef1c8599b382
- 최대 2회 호출 확인: core 1회(약 4.0초), extensions 1회(약 5.5초)
- 두 호출 모두 모델 응답과 usage metadata를 반환했지만, 병합 전 애플리케이션 검증에서 INVALID_MODEL_OUTPUT으로 거절되어 HTTP 502 반환.
- Worker 로그상 analysis.parallel.failed만 기록되어 있어, 저장되지 않은 모델 원문 없이 어느 필드가 실패했는지 확정할 수 없음. Google 503은 이번 재실행에서는 관측되지 않음.
- 응답 결과가 없으므로 3.8 모델의 수학 품질이나 완료 시간 개선은 판단하지 않음. 추가 호출 없이 로컬 Worker를 종료.

## 2026-09-22 한국어 혼합 수식 렌더링 및 practice 502 보완

- `problemLatex`에 한국어 문장과 `\\text{...}`, `\\[...\\]` 수식이 섞여도 한국어는 일반 텍스트로, 수식 조각은 KaTeX로 분리 렌더링하도록 프론트엔드를 보완했습니다.
- 모델이 반환한 `\\begin{aligned}...\\end{aligned}` 조건 블록은 줄 단위로 렌더링하고, `\\fracqp`처럼 괄호가 빠진 단순 분수 오탈자는 화면에서 보정합니다. 동시에 다음 분석부터는 aligned 환경을 생성하지 않도록 branch prompt를 제한했습니다.
- KaTeX 자체 호스팅 폰트가 Vite 번들에서 `data:` URI로 로드될 수 있어 Pages CSP의 `font-src`에 `data:`를 추가했습니다.
- `/api/practice`의 출력 상한이 `1024`여서 복잡한 원문에서 사고 토큰과 JSON 결과가 잘릴 수 있었습니다. `GEMINI_PRACTICE_MAX_OUTPUT_TOKENS=4096`을 별도 설정하고 실패 진단 로그를 추가했습니다.
