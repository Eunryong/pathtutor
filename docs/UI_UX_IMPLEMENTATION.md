# PathTutor 학습 노트 UI

## 구현 범위

- 밝은 회색 배경과 흰 종이, 파란색 경로 선택, 청록 피드백, 적갈색 오류 표시.
- 데스크톱의 입력·소개 2열 구성과 모바일 단일 열 구성. 모바일에서는 소개용 수식 노트를 숨겨 입력 접근을 단축.
- 이미지 끌어 놓기·텍스트 영역에 이미지 붙여넣기·교체·삭제·원본 확대 링크.
- 내 풀이 첨삭 / 문제만 질문 구분. 문제만 질문은 표준 풀이를 우선 표시하고 참고 점수를 숨김.
- 분석 중 실제 경과 시간, 원본 확인, 취소. 서버 처리·비용까지 취소되는 것은 아님을 안내.
- 첫 오류 자동 선택, 단계선 탐색, 수정 풀이 펼치기, 원본 확인.
- 데스크톱 병렬 비교 / 모바일 풀이 전환. 단계 간 자동 대응은 제공하지 않음.
- 선택 경로 누락 사유, 접힌 AI 참고 평가, 유사 문제 버튼 일원화.
- 직접 작성한 오프라인 예시 결과와 연습 문제. 실측 응답이나 모델 평가 자료가 아님.
- 키보드 포커스, 본문 건너뛰기, 한국어 문서 언어, reduced-motion 지원.

## 검증 범위와 남은 확인

- Vitest의 mock·계약·컴포넌트·상태 테스트와 TypeScript 검사, 프로덕션 빌드.
- Aside에서 데스크톱 입력·예시 결과·첨삭·비교 확인. 모바일은 360px iframe으로 확인하며 실제 기기 검증을 대체하지 않음.
- 실제 Gemini 호출, OCR 품질·응답 시간·비용의 신규 측정은 수행하지 않음.
- 제목·브랜드는 SUIT Variable, 본문은 Pretendard Variable, 수식은 KaTeX를 자체 호스팅. 글꼴은 font-display: swap으로 대체 글꼴을 허용하며, Pretendard는 unicode-range 서브셋을 사용. OFL 원문은 public/licenses에 포함.
- 모든 브라우저·스크린리더에 대한 접근성 인증 수준의 검증은 남아 있음.
- API 스키마를 변경하지 않았으므로 문제만 질문의 studentPath는 '문제 풀이'로 표시. 모델이 학생 풀이를 생성하지 않는지에 대한 실응답 평가는 별도 승인 필요.
- 네트워크 오류 복구는 App + 실제 API 클라이언트 + mocked fetch로 회귀 검증. 연결 실패·504 timeout·503 HTML 오류 뒤 입력 보존, 수동 재요청, 요청 취소 및 포커스 이동 확인.

## 2026-09-10 보완 검증

- 전체 자동 테스트 63개 통과. 입력·결과 화면의 axe-core 의미 구조 검사 포함. JSDOM에서는 색 대비 검사를 제외하고 Aside 브라우저에서 별도 확인.
- 브라우저의 모든 fetch를 고정 응답으로 교체한 뒤 연결 실패 → timeout → 성공을 3회 수동 요청으로 확인. 실제 Gemini 요청은 없음.
- 운영 Worker health 200, Pages Origin의 POST /api/analyze preflight 204와 허용 Origin 헤더 확인. 이는 분석 품질·Gemini 응답 성공 검증이 아님.
- 입력 모드·풀이 경로를 이름 있는 그룹으로 표시하고 입력칸에 오류 설명 연결. 파일 교체·삭제 링크/버튼에 최소 44px 터치 영역 적용.
- 결과 화면 WCAG 2 A/AA 및 2.1 AA 자동 검사: 위반 0, 수동 확인 필요 항목 0. 자동 검사가 전체 접근성을 보장하지는 않음.
- 입력의 노트 줄무늬는 자동 대비 판정의 한계가 있어 수동 계산 병행. 작은 글씨 뒤 단색 배경을 적용했고 해당 글씨의 대비는 최소 약 4.65:1.

## 남은 수동 확인

- iOS Safari / Android 실제 기기: 이미지 선택·붙여넣기·가상 키보드·가로 화면.
- VoiceOver / TalkBack: 입력 오류 읽기, 결과 전환 안내, 수식 읽기, 단계 이동.
- 실제 모델 출력 품질과 성능·비용 비교는 기존 실호출 중단 지시에 따라 보류.
- 운영 확대용 분산 quota·비용 상한·비동기 jobs는 이번 UI 보완 범위에 포함하지 않음.
